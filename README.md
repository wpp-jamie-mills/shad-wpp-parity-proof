# WPP shadcn parity proof gallery

Static proof gallery comparing the official WPP Open components
(`@wppopen/components-library@4.6.0`) with the Base UI and Radix shadcn
registries.

- `index.html` — proof sheets and gallery entry point
- `proof-sheet-1440.html` and `proof-sheet-390.html` — filterable proof sheets
- `gallery.html` — all component side-by-sides
- `components/<name>.html` — per-component comparisons
